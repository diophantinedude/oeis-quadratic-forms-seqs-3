Fifteen stuck sequences, one construction

Both predecessor repos ended on the same open problem — the class-number-3 construction, called “highest value, and genuinely hard”. The obstruction was not the class number. It was insisting the representation count be a scalar multiplicative function. In the group ring Z[Cl(Δ)] it is multiplicative for every discriminant, and the whole family collapses at once.

What made each one hard

The tiers are the historical order in which each became solvable — not a ranking

A

Class number one

Every ideal of norm k lies in one class, so the count is a plain multiplicative function. This is the case repo 1 solved, and the only case it could.

8 entries · A328151, A374158, A374159, A374090, A374094, A374285, A374286, A300419

B

One class per genus

h > 1, but every class has order ≤ 2, so a genus character decides the count. Repo 2’s refinement — correct, and still narrower than the truth.

1 entry · A374288  (Δ = −20, h = 2)

C

Class number three — the named open problem

h = 3 is odd, so one genus holds all three classes and characters give no purchase. Both repos stopped here. The group ring does not care: 61 and 55 sieve-bound terms became 501 constructed ones.

2 entries · A374160 (Δ = −44), A374161 (Δ = −76)

D

Indefinite forms

Δ = +5, so the unit group is infinite and both repos filed it as “needs the fundamental unit of Q(√5) — new mathematics”. It needs none: the entries constrain x, y > 0, and that region holds exactly one representative per ideal except on squares.

Patterns worth keeping

Three that fell out of having all fifteen in one engine

Higher class number makes the terms smaller

Counter-intuitive, and clear once you see it. A larger class group gives the minimiser more distinct factorisation patterns that hit a given count, so it is rarely forced onto a single prime at a huge exponent. At h = 1 the terms blow up on prime n — a(n) then needs one split prime raised to 2n−2 — while at h = 3 the curve stays almost flat.

A published conjecture, explained

A374159 carries the comment “Conjecture: All terms are multiple of a(1) = 8.” It holds on all 500 terms we now have — and the construction says why. Δ = −28 is a conductor-2 order in which 2 splits upstairs, so the local factor at 2 is e−1: a factor of 2 in the count costs 2³ = 8, where the cheapest split prime available is 11. Powers of two simply dominate every minimiser. 8 is also sharp — a(1) = 8 itself is the one term not divisible by 16.

These entries are stuck at small numbers, not big ones

The term each entry is blocked on — the first one past its published data — has a median of 4.3 × 10⁹, and 14 of the 15 sit below 10¹³. All of them are well inside what an afternoon of sieving reaches. They are stuck because the published programs enumerate representations one at a time, not because the next value is out of reach. That is the founding observation of this project, quantified.

Where this goes next

The family is finished; the interesting work has moved elsewhere

  1. Closed — do not reopen

    Binary quadratic forms

    One engine covers every entry at any class number and either sign of discriminant, with no bound on k. A sweep of all 398,020 corpus entries found no sixteenth. The predecessors’ top-ranked target (“other idoneal discriminants — best value-per-effort”) is closed out: OEIS carries no such entry for any D outside {1, 2, 3, 5, 7, 11, 19}.

  2. Next — same idea, different group

    Divisors in a residue class

    The content was never “class groups”. Any count that is a character combination of multiplicative functions is a function of the factorisation. Swap Z[Cl(Δ)] for Z[(Z/m)*] and the same machinery constructs A343105 — “smallest number with exactly n divisors of the form 8k+3”, 39 published terms. No GPU needed; this is CPU-cheap.

  3. Next — where the GPU actually changes the frontier

    Genuinely combinatorial searches

    Sequences with no multiplicative structure have depth as their only lever, which is exactly what a GPU buys. Equal sums of like powers (the Waring work, A342893–A342901, A345864), congruence-pruned tuple searches (A384132, A290400), and the stalled frontiers A135578 and A306968–70. The published bounds on all of these are CPU-era.

  4. Free adjacency — already computed

    A327796 / A327797

    The x and y values realising A300419(n), which we hold to n = 2500. Cornacchia on the known factorisation yields the representations and per-term certificates — the strongest rung on the validation ladder, and something this class has never had.
